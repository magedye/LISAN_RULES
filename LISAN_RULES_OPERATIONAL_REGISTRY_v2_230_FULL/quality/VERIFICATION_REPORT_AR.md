# تقرير تحقق حزمة قواعد لسان القرآن v2

**نوع الاختبار:** فحوص بنية ومعالجة ملفات محلية؛ **ليس** مراجعة علمية دلالية أو اختبارًا لإضافة مثبتة.

| التحقق | النتيجة | النطاق |
|---|---|---|
| قراءة ملفات المرفقات الأربعة | PASS | مسودات المستخدم الأربع من المسارات المرفقة |
| الحفاظ على البنود التاريخية | PASS | مطابقة قيم كل خلية في الصفوف 001–190 للأعمدة الـ13 مع CSV السابق |
| عدد البنود ومعرّفاتها | PASS | 230 صفًا بمعرفات فريدة وتسلسل حتى 230 |
| إضافات مترجمة | PASS | 40 صياغة إضافية عربية/إنجليزية غير فارغة |
| تكرار حرفي إنجليزي | PASS | لا يوجد تكرار مطابق للنصوص؛ **لا يعني هذا غياب التكرار المعنوي** |
| ملحق مصدر/تميّز الـ40 | PASS | مصدر مقترح وأقرب حكم قديم وسبب تمايز لكل بند |
| فحص التشابه اللفظي | PASS كإجراء | 40 صفًا بمرشحات التشابه؛ قرار التكرار الدلالي البشري **معلق** |
| ملفات الانطباق والتطبيق | PASS بنيويًا | 230 صفًا بها حقول؛ الـ190 الأصلية **CATEGORY_BASED_INFERENCE** فقط |
| عدد قوالب الاختبارات | PASS بنيويًا | 460 حالة إيجابية وسلبية، كلها NOT_RUN |
| عدد مؤشرات الأثر | PASS بنيويًا | 13 تعريفًا؛ كل القيم الفعلية غير مدخلة |
| JSON Schema | PASS | 230 سجلًا محليًا مطابقًا للمخطط المقترح باستخدام jsonschema |
| Excel | PASS | إنشاء 24 ورقة، فحص النطاقات الحرجة، 0 أخطاء صيغ مرصودة في الفحص |
| جاهزية سلطة القواعد | NOT_VERIFIED | تحتاج مصدرًا معتمدًا ومراجعًا وصاحب سلطة |
| تشغيل الإنفاذ في المضيف والخادم | NOT_RUN | لا اختبارات live ولا تعديل خدمة |
| أثر القواعد على نموذج حقيقي | NOT_MEASURED | لا baseline/treatment ولا عينة تحكيم دلالي |
| اعتماد أو نشر بحث دلالي | NOT_GRANTED | خارج المهمة |

**ملاحظة عن KPI:** `risk_tier` تقدير تصميمي أولي، وليس درجة تأثير أو احتمال نجاح أو ثقة دلالية. خلايا `baseline_events`, `treatment_events` والمقامات في Excel فارغة؛ المعادلات تظهر خالية حتى الإدخال. وعدّ «اختبارات أثر اجتازت» الظاهر 0 يعني عدم وجود نتائج PASS مسجلة، لا الفشل النظري لكل قاعدة.

**المخرجات التي لا يجوز استنتاجها:** وجود حزمة Excel لا يثبت صحة تعريف قرآني، ووجود حقل `SERVER_POLICY` لا يثبت تشغيل Server Gate، ووجود `SOURCE_DERIVED_PROPOSAL` لا يثبت أن الوثيقة مسلَّمة في مرتبة معتمدة. التقييم البشري والاختبارات الفعلية مطلوبة قبل أي ترقيات رسمية.
