# إعدادات مرجعية فقط

الملف `librechat.research-trial.reference.yaml` مشتق من ملف تجربة baseline بلا تعديل في أصل النسخة. الفرق المادي الوحيد في السياسة: `mode: dontAsk`، لرفض الأدوات غير المطابقة لقائمة السماح المصرح بها. `deny` قائم أيضًا، ولا تُفعَّل عمليات حفظ واعتماد ونشر كنموذج أداة.

**توقف قبل نسخه إلى LibreChat:** ملفه يحوي أمثلة Windows من بيئة سابقة (`D:/APP/...`) ولا ينبغي نسخه كما هو. تحقق من إصدار LibreChat الفعلي، Schema وإعدادات الأمان الأخرى وحالة المستودع، ثم عدل نسخة تجريبية منفصلة. لا تستخدم `CONFIG_BYPASS_VALIDATION` لتعطيل الإخفاقات.

مهارات baseline الـ19 تُحفظ كما هي. لا تضف `allowed-tools` مضمونة الصلاحية لأي منها اعتمادًا على النص. لا تضف `lisan_gov.public_mcp` إلى الوكلاء الحاليين؛ هو مثال قراءة رسمية لم يستوفِ AuthN/tenant isolation/منع مخرجات الدردشة.
