بناءً على طلبك، قمتُ بحصر المكونات الوظيفية في LibreChat التي يمكن **إعدادها والتحكم بها** (سواء عبر `librechat.yaml`، أو واجهة الإدارة، أو Agent Builder). هذا الحصر مُوجّه لمساعدتك في تحديد ما يمكن توظيفه لتحقيق أهداف **مشروع لسان القرآن (Quran Lisan)**.

---

## 1. الواجهة وتجربة المستخدم (Interface & UX)

هذه الإعدادات تُتحكم بها بشكل أساسي عبر كائن `interface` في `librechat.yaml`، وتؤثر على ما يراه المستخدم ويستطيع الوصول إليه.

| المكوّن | ما يمكن التحكم به | الصلة المحتملة بـ Quran Lisan |
| :--- | :--- | :--- |
| `customWelcome` | نص رسالة الترحيب المخصصة | وضع ترحيب تعريفي بالمشروع أو بمنهج "لسان القرآن". |
| `modelSelect` | إظهار/إخفاء قائمة اختيار النموذج | تقييد المستخدم بنماذج محددة مناسبة للمحتوى العربي/القرآني. |
| `parameters` | إظهار/إخفاء لوحة معاملات النموذج (Temperature, Max Tokens) | منع العبث بإعدادات حساسة أو السماح بضبط دقة الاسترجاع. |
| `presets` | تفعيل/تعطيل نظام الإعدادات المسبقة (Presets) | توفير إعدادات جاهزة لمهام مثل "شرح آية" أو "تحليل نحوي". |
| `prompts` | تفعيل/تعطيل مكتبة الأوامر (Prompts) والتحكم في صلاحيات الإنشاء والمشاركة | بناء مكتبة أوامر جاهزة للأسئلة القرآنية واللغوية. |
| `bookmarks` | تفعيل/تعطيل الإشارات المرجعية للمحادثات | حفظ المحادثات المهمة للرجوع إليها. |
| `multiConvo` | تفعيل/تعطيل المحادثات المتعددة | مقارنة تفاسير أو آراء نحوية في نفس الوقت. |
| `temporaryChat` | تفعيل المحادثات المؤقتة (بدون حفظ) | طرح أسئلة حساسة أو تجريبية دون أثر دائم. |
| `fileSearch` | تفعيل البحث في الملفات كميزة في واجهة الدردشة | تمكين المستخدم من رفع ملفات (كتب تفسير، معاجم) والبحث فيها. |
| `fileCitations` | تفعيل الاستشهادات عند استخدام البحث في الملفات | إظهار المصدر بدقة (الكتاب، الصفحة) وهو أمر جوهري للتوثيق. |
| `peoplePicker` | التحكم في اختيار المستخدمين/المجموعات/الأدوار | إدارة من يمكنه مشاركة المحادثات أو الوصول إليها. |
| `sharedLinks` | تفعيل/تعطيل روابط المشاركة | نشر محادثات أو إجابات مختارة. |
| `runCode` | تفعيل/تعطيل مشغل الكود (Code Interpreter) | تحليل بيانات أو نصوص برمجياً (قد يكون مفيداً لمعالجة النصوص). |
| `webSearch` | تفعيل/تعطيل البحث في الويب | البحث عن مصادر خارجية (مع مراعاة الدقة والأمانة العلمية). |
| `contextUsage` / `contextCost` | إظهار استهلاك السياق والتكلفة | مراقبة الموارد عند تحليل نصوص طويلة. |
| `defaultPinnedTools` | تثبيت أدوات افتراضية معينة | تسهيل الوصول السريع لأدوات البحث في الملفات. |

## 2. النماذج ومزودو الخدمة (Models & Providers)

هذه هي القدرة على تحديد **من** يولد الإجابة وكيف، وتُدار عبر `librechat.yaml` (للنقاط النهائية) و`.env` (للمفاتيح).

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **مزودون أصليون** | OpenAI, Anthropic, Google, Azure, AWS Bedrock, Vertex AI, وغيرها. |
| **`endpoints.custom`** | إضافة أي API متوافق مع OpenAI (مثل OpenRouter، Ollama، LM Studio، vLLM) مع `baseURL` و`apiKey` و`models.default` و`fetch` و`dropParams`. |
| **`modelSpecs`** | تحديد مواصفات نماذج معينة وفرضها (`enforce`) أو إعطائها أولوية (`prioritize`). |
| **`models.default`** | قائمة النماذج الافتراضية المتاحة لكل نقطة نهاية. |
| **`fetch`** | جلب قائمة النماذج تلقائياً من المزود عند الدعم. |
| **`modelDisplayLabel`** | تسمية مخصصة تظهر للمستخدم. |
| **المعاملات لكل نموذج** | عبر واجهة الدردشة أو Presets: `temperature`, `top_p`, `max_tokens`, `presence_penalty`, `frequency_penalty` وغيرها. |
| **اختيار النموذج لكل وكيل** | عبر Agent Builder: ربط كل وكيل بنموذج مختلف حسب المهمة. |

**الصلة بـ Quran Lisan:** يمكنك استخدام نموذج قوي للتحليل اللغوي العميق، ونموذج أسرع للاسترجاع، ونموذج متخصص في العربية إن وُجد، مع توجيه كل مهمة إلى النموذج الأنسب.

## 3. الوكلاء (Agents)

الوكلاء هي الكيانات القابلة للتخصيص لأداء مهام متخصصة. تُدار عبر `interface.agents` وصلاحيات الأدوار وAgent Builder.

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **إنشاء/تعديل/حذف وكيل** | الاسم، الوصف، التعليمات (System Prompt)، الأيقونة، الفئة. |
| **`interface.agents`** | `use`, `create`, `share`, `public` – صلاحيات المستخدمين على الوكلاء. |
| **نموذج الوكيل** | اختيار مزود/نموذج محدد لكل وكيل. |
| **المهارات (Skills)** | تفعيل/تعطيل `skills_enabled` لكل وكيل، واختيار المهارات المتاحة له. |
| **الأدوات (Tools)** | ربط أدوات MCP محددة، وCode Interpreter، وActions، وPlugins. |
| **الإعدادات المتقدمة** | `Recursion Limit` (حد الخطوات للمهام المتعددة)، وغيرها. |
| **الوكلاء الفرعيون (Subagents)** | تحديد الوكلاء الذين يمكن للمنسق تفويض المهام إليهم، ومنع التفويض الذاتي (`allowSelf: false`). |
| **فئات الوكلاء** | تخصيص التصنيفات (Management, Structural, Review, ...) إن كانت مدعومة في نسختك. |
| **Agent Plugins** | تجميع مهارات وخوادم MCP وأوامر في حزمة قابلة للنشر. |

**الصلة بـ Quran Lisan:** يمكن بناء وكلاء مثل: "وكيل التفسير"، "وكيل الإعراب"، "وكيل المفردات"، "وكيل المراجعة العلمية"، "وكيل صياغة الدروس"، مع ربط كل منهم بمهاراته وأدواته ونموذجه.

---

## 4. المهارات (Skills)

المهارات هي حزم تعليمات (`SKILL.md`) قابلة لإعادة الاستخدام، ويمكن أن تعمل يدوياً أو تلقائياً أو في كل دور.

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **إنشاء مهارة** | عبر واجهة Skills أو برفع `SKILL.md`. |
| **`skills_enabled`** | مفتاح رئيسي لتفعيل المهارات على مستوى الوكيل. |
| **التفعيل التلقائي** | `Available to agent` – جعل المهارة متاحة أو نشطة افتراضياً. |
| **صلاحيات المهارات** | من يمكنه الاستخدام/الإنشاء/المشاركة/النشر العام. |
| **مهارات النشر (Deployment Skills)** | مهارات تُحمّل من حزم Agent Plugins. |

**الصلة بـ Quran Lisan:** يمكن تحويل المنهجية التعليمية لـ "لسان القرآن" إلى مهارات: "شرح قاعدة نحوية"، "تحليل جملة قرآنية"، "ربط الآية بالدرس"، "توليد تمرين"، إلخ.

---

## 5. المشاريع (Projects)

المشاريع في LibreChat هي مساحات عمل ذات سياق مشترك، ويمكن تخصيصها.

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **إنشاء مشروع** | تنظيم المحادثات ضمن مشروع. |
| **تعليمات المشروع** | System Prompt لكل مشروع يتجاوز التعليمات العامة. |
| **ملفات المعرفة (Project Knowledge)** | ربط ملفات مرجعية (كتب، معاجم، مناهج) بالمشروع. |
| **ذاكرة المشروع (Project Memory)** | ذاكرة معزولة لكل مشروع لا تتسرب لغيره. |
| **إعدادات افتراضية للمشروع** | وكيل/نموذج افتراضي وأدوات/خوادم MCP مفعلة تلقائياً عند فتح المشروع. |
| **الاحتفاظ والتاريخ** | TTL لكل مشروع، تثبيت/عدم انتهاء، أرشفة/تصدير مستقل. |

**الصلة بـ Quran Lisan:** إنشاء مشاريع مثل "دورة المستوى الأول"، "تفسير سورة البقرة"، "معجم المفردات" — كل منها بملفاته وتعليماته وذاكرته.

## 6. الذاكرة (Memory)

الذاكرة في LibreChat يمكن أن تكون عامة أو معزولة حسب الوكيل أو المشروع.

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **الذاكرة العامة** | Key-Value تُضاف يدوياً من الواجهة (ثوابت المكتب، التفضيلات). |
| **ذاكرة الوكيل** | `optionally isolated memory` – يمكن عزل ذاكرة كل وكيل. |
| **ذاكرة المشروع** | ذاكرة خاصة بالمشروع لا تتسرب لغيره. |
| **إعدادات الذاكرة في `librechat.yaml`** | كائن `memory` لضبط سلوك الذاكرة والتخصيص. |
| **استهلاك السياق** | عرض استخدام النافذة الحالية والتوكنات والتكلفة. |

**الصلة بـ Quran Lisan:** يمكن تخزين تفضيلات مثل "لغة الشرح: العربية"، "منهج التفسير المفضل"، "مستوى الطالب" في الذاكرة العامة، مع عزل تقدم كل طالب أو مجموعة في ذاكرة المشروع.

## 7. الإعدادات المسبقة (Presets) والأوامر (Prompts)

هذان مكونان مختلفان: **Preset** يحفظ إعدادات المحادثة كاملة (النموذج، المعاملات، System Prompt)، بينما **Prompt** هو نص/قالب قابل لإعادة الاستخدام.

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **Presets** | حفظ/تحميل إعدادات كاملة، تعيين Preset افتراضي، مشاركة. |
| **محتوى Preset** | النموذج، System Prompt، المعاملات، أيقونة، رسالة ترحيب أولية. |
| **Prompts** | إنشاء/استخدام/مشاركة/نشر قوالب أوامر. |
| **استدعاء Prompt** | كتابة `/` في مربع الدردشة لاختيار أمر محفوظ. |
| **Placeholders** | قوالب بأماكن شاغرة يتم ملؤها قبل الإرسال. |

**الصلة بـ Quran Lisan:** Preset لمهمة "تحليل آية": يحدد النموذج المناسب، وSystem Prompt المتخصص، والمعاملات. Prompt لقالب "أعرب الجملة التالية" أو "استخرج المفردات".

## 8. الأدوات والتكاملات (Tools & MCP)

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **خوادم MCP** | تعريف `mcpServers` (stdio أو streamable-http) وربط أدواتها بالوكلاء. |
| **صلاحيات MCP** | `use`, `create`, `share`, `public` لكل دور/مستخدم. |
| **Code Interpreter** | تفعيل/تعطيل، صلاحيات الكتابة والتنفيذ (Ask/Allow/Deny). |
| **Actions / OpenAPI** | ربط وكلاء بواجهات برمجية خارجية. |
| **Plugins** | حزم تجمع مهارات + MCP + أوامر. |
| **`actions.allowedDomains`** | تقييد النطاقات المسموح للوكلاء بالوصول إليها. |

**الصلة بـ Quran Lisan:** يمكن بناء MCP متخصص للبحث في نصوص القرآن أو المعاجم أو قواعد البيانات، وربطه فقط بوكلاء البحث والمراجعة.

## 9. التحكم في الوصول والأمان (Access Control)

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **الأدوار (Roles)** | صلاحيات دقيقة لكل دور (استخدام/إنشاء/مشاركة/نشر) للوكلاء، المهارات، MCP، إلخ. |
| **لوحة الإدارة (Admin Panel)** | إدارة مصفوفة الصلاحيات لكل دور، بما فيها الأدوار المخصصة. |
| **`registration`** | تسجيل الدخول الاجتماعي، النطاقات المسموحة للتسجيل. |
| **`rateLimits`** | حدود رفع الملفات، استيراد المحادثات، لكل IP/مستخدم. |
| **`balance` / `transactions`** | نظام رصيد التوكنز والخصم والمعاملات. |
| **`retentionMode` / `temporaryChatRetention`** | سياسات الاحتفاظ بالمحادثات. |

**الصلة بـ Quran Lisan:** التحكم في من يمكنه الوصول للمحتوى، ومن يمكنه إنشاء مهارات أو وكلاء، ووضع حدود لاستخدام الموارد.

## 10. التشغيل الآلي والجدولة (Automation)

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **Scheduled Chats** | تشغيل وكلاء محفوظين وفق Cron أو Presets، مع مناطق زمنية وتكرار أسبوعي. |
| **Agent Events** | استقبال أحداث مُصادقة لتشغيل وكلاء، مع صناديق بريد لكل فاعل وتوقف بشري. |
| **Background Tools** | تشغيل أدوات (Code Interpreter، MCP) في الخلفية أثناء استمرار الوكيل. |
| **Human-in-the-loop** | إيقاف الوكيل لطلب موافقة أو إدخال، مع استئناف متين. |

**الصلة بـ Quran Lisan:** جدولة "تذكير يومي بآية" أو "تقرير أسبوعي بتقدم الطلاب"، مع إمكانية موافقة بشرية قبل نشر أي محتوى.

## 11. معالجة الملفات والبحث (Files & Search)

| المكوّن | ما يمكن التحكم به |
| :--- | :--- |
| **File Search / RAG** | تفعيل البحث الدلالي في الملفات، مع إعدادات التقطيع والاستشهادات. |
| **File Citations** | التحكم في عدد الاستشهادات وحدودها (`maxCitations`, `minRelevanceScore`). |
| **رفع الملفات** | حدود الرفع، أنواع الملفات، استراتيجيات التخزين (`fileStrategies`). |
| **OCR** | استخراج النص من الصور والمستندات الممسوحة (حسب النسخة). |
| **Artifacts** | إنشاء وعرض مخرجات (ملفات، كود، مستندات) داخل المحادثة. |

**الصلة بـ Quran Lisan:** رفع نسخ رقمية من كتب التفسير أو المناهج والبحث فيها مع استشهادات دقيقة، أو استخراج نصوص من صور صفحات.

## 12. ما يجب التحقق منه في نسختك المثبتة

بعض الميزات المذكورة أعلاه قد تكون **تجريبية** أو تعتمد على إصدار LibreChat المثبت:

- **فئات الوكلاء المخصصة**: ليست كل النسخ تدعم تخصيص الفئات عبر `librechat.yaml`؛ تحقق من `interface.agents` أو من لوحة الإدارة.
- **Presets**: تأكد من أنها ما تزال مدعومة وقابلة للاستيراد/التصدير في نسختك قبل بناء JSON.
- **Project Knowledge / Project Memory**: قد تكون ضمن إصدار أحدث أو قيد التطوير؛ تحقق من الإصدار المثبت.
- **Agent Skills**: تأكد من تفعيل `skills_enabled` وصلاحيات المهارات.
- **Scheduled Chats / Agent Events**: قد تكون تجريبية أو تحتاج إعداداً إضافياً.

## الخلاصة: كيف يوظف هذا لصالح Quran Lisan؟

المكونات القابلة للتحكم تتيح بناء منظومة تعليمية/بحثية متكاملة:

1. **الهيكل**: مشاريع لكل مستوى أو سورة أو دورة، مع ملفات معرفة وتعليمات وذاكرة معزولة.
2. **الفريق**: وكلاء متخصصون (تفسير، إعراب، مفردات، مراجعة) لكل منهم نموذجه ومهاراته وأدواته.
3. **المعرفة**: رفع الكتب والمناهج والبحث الدلالي فيها مع استشهادات دقيقة.
4. **التفاعل**: Presets لمهام متكررة، Prompts لقوالب أسئلة، Conversation Starters (إن وجدت) لبدء سريع.
5. **الأتمتة**: جدولة مهام، تشغيل خلفي، وموافقة بشرية قبل النشر.
6. **الحوكمة**: أدوار وصلاحيات، حدود استخدام، وعزل بيانات المشاريع.

بهذا الحصر، يمكنك تحديد **أي المكونات ستُعدّ يدوياً**، و**أيها سيُبنى عبر MCP أو Skills**، و**أيها يحتاج تحققاً من النسخة المثبتة** قبل الاعتماد عليه.
