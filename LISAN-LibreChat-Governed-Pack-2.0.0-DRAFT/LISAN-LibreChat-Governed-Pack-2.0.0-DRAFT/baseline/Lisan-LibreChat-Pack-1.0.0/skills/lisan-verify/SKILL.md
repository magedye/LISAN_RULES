# lisan-verify

هذه مهارة إجرائية ضمن حزمة لسان 1.0.0، وليست مصدرًا دلاليًا أو صلاحية جديدة. تُطبق مع تعليمات الوكيل الثابتة. لا توسع الأدوات ولا تمنح قبولًا؛ لا ملف allowed-tools فيها. استدعها عند تحقق وصفها فقط.

حدد نسخة المدخل ونطاق المراجعة. افحص المصدر والاقتباسات والعد والتغطية ودعم الادعاءات والاعتراضات وسجل التعرض المتاح. استخدم مخططات الأدوات الفعلية، ولا تصنع سجلًا يمر شكليًا لإخفاء نقص. صنف ملاحظاتك المؤكدة والاشتباهات وما لا تستطيع التحقق منه. أعط أثر كل خطأ على الدعوى والتصحيح المطلوب. هذه مراجعة داخلية ما لم تثبت شروط استقلال منفصلة؛ نجاح الأداة لا يساوي صحة المعنى.

في المسار الداخلي تقتصر الأدلة الأولية على المتن المسترجع. نتائج البحث السابق والمصادر الخارجية لا تدخل إلا في مقارنة معلنة منفصلة. عند التعذر بيّن النقص ولا تستبدل الأدلة بذاكرة النموذج. أخرج ما نُفذ فعلًا وما بقي، مع مراجعة دلالية غير مدعاة وثقة غير مختلقة.


فحص ظاهر خفيف: البداية من تعريف معجمي، تسرب تفسير مسبق للسياق، الاستناد إلى مشهور بلا شاهد، نقل تفسير خفي، توحيد متكلف للجذر، مفهوم فضفاض يفسر كل شيء، الإفراط في دلالات الحروف، والتأكيد الدائري. لكل مؤشر سجل الموضع والدليل والأثر وما لم يمكن تقييمه. لا تحكم بالتلوث من التشابه مع التراث وحده ولا تسجل CLEAR إذا لم تنفذ فحصًا كافيًا. مقارنة نصوص خارجية فعلية من اختصاص COMPARE بعد حفظ نسخة النتيجة؛ لا توسع أدوات AUDIT الداخلية.
