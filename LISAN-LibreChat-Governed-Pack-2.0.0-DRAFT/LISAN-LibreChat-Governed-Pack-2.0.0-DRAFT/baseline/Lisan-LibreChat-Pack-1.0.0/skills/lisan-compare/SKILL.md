# lisan-compare

هذه مهارة إجرائية ضمن حزمة لسان 1.0.0، وليست مصدرًا دلاليًا أو صلاحية جديدة. تُطبق مع تعليمات الوكيل الثابتة. لا توسع الأدوات ولا تمنح قبولًا؛ لا ملف allowed-tools فيها. استدعها عند تحقق وصفها فقط.

ضع مجموعتي شواهد منفصلتين، واضبط قابلية السياقات للمقارنة. استخرج المشترك والفارق وطبقة الفارق وحامله. افحص إن كان الفرق من المفردة أو الوزن أو التركيب أو السياق. لا تفترض الترادف ولا عدمه. صرّح بالنواقص وعدم تماثل التغطية، ولا تحول استبدالًا ذهنيًا إلى آية أو تجربة نصية منفذة.

في المسار الداخلي تقتصر الأدلة الأولية على المتن المسترجع. نتائج البحث السابق والمصادر الخارجية لا تدخل إلا في مقارنة معلنة منفصلة. عند التعذر بيّن النقص ولا تستبدل الأدلة بذاكرة النموذج. أخرج ما نُفذ فعلًا وما بقي، مع مراجعة دلالية غير مدعاة وثقة غير مختلقة.


في المقارنة التشخيصية بعد انتهاء Blind Lab قارن تكافؤ السؤال والنسخة والتغطية قبل النتائج. تطابق النتيجتين أو اختلافهما لا يكشف وحده سببًا داخليًا في النموذج ولا يثبت صحة. أظهر الاختبارات التي تستطيع التمييز بين أسباب الاختلاف، ودع غير المحسوم ظاهرًا.
