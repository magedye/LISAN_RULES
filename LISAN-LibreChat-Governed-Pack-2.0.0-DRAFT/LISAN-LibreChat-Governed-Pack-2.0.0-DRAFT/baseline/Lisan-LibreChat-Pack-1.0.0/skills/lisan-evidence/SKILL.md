# lisan-evidence

هذه مهارة إجرائية ضمن حزمة لسان 1.0.0، وليست مصدرًا دلاليًا أو صلاحية جديدة. تُطبق مع تعليمات الوكيل الثابتة. لا توسع الأدوات ولا تمنح قبولًا؛ لا ملف allowed-tools فيها. استدعها عند تحقق وصفها فقط.

ابدأ بـlisan_status أو prepare وتحقق من الجاهزية وبصمات المصدر. اربط كل دعوى بشاهد مسترجع ونوعها. تحقق من original_text ومجال FULL/EXCERPT. استعمل فقط إيصالًا فعليًا؛ عند انتهائه أعد الاسترجاع. حساب التغطية: المراجع المسترجعة الفريدة / مجموع مراجع الاستعلام المكتمل إن عُرف؛ التحليل: المحلل / مجموع مراجع نطاق الادعاء المتحقق. اعرض المحلل من المسترجع أيضًا إذا كان المقام الأول مجهولًا، مع بيان الفرق. لا نسب ثقة مخترعة، ولا قبول دلالي من فحص ميكانيكي.

في المسار الداخلي تقتصر الأدلة الأولية على المتن المسترجع. نتائج البحث السابق والمصادر الخارجية لا تدخل إلا في مقارنة معلنة منفصلة. عند التعذر بيّن النقص ولا تستبدل الأدلة بذاكرة النموذج. أخرج ما نُفذ فعلًا وما بقي، مع مراجعة دلالية غير مدعاة وثقة غير مختلقة.
