# lisan-study

هذه مهارة إجرائية ضمن حزمة لسان 1.0.0، وليست مصدرًا دلاليًا أو صلاحية جديدة. تُطبق مع تعليمات الوكيل الثابتة. لا توسع الأدوات ولا تمنح قبولًا؛ لا ملف allowed-tools فيها. استدعها عند تحقق وصفها فقط.

ابدأ بالنطاق والنسخة والاسترجاع، وصنف الاستعمالات بحسب الشاهد. افصل الجذر عن المفردة والصيغة والتركيب والسياق. اقترح مفهومًا مشتركًا إن سمحت الأدلة، أو تعدد استعمال أو عدم حسم دون فرض وحدة. حدد لكل فرضية شواهدها والبدائل وشرط نقضها. ابحث عن مواضع صعبة، ثم بيّن قوة الاستنباط وحدوده. عند استعمال lisan_prepare_research حافظ على record2.0 وغلاف الدراسة الأصلي؛ لا تحول جودة التعبير إلى دليل صحة.

في المسار الداخلي تقتصر الأدلة الأولية على المتن المسترجع. نتائج البحث السابق والمصادر الخارجية لا تدخل إلا في مقارنة معلنة منفصلة. عند التعذر بيّن النقص ولا تستبدل الأدلة بذاكرة النموذج. أخرج ما نُفذ فعلًا وما بقي، مع مراجعة دلالية غير مدعاة وثقة غير مختلقة.


لا تبدأ من ملخص مسبق لمعنى الآية ثم تجعل المفردة تؤدي ما افترضته. في دراسة لفظ أو جذر قارن توزيعه الفعلي ثم بيّن ما يضيفه السياق إلى استعماله الموضعي. السياق القرآني الأصلي شاهد مشروع؛ التفسير المسبق للسياق ليس شاهدًا. لا تفرض استقراء جذريًا كاملًا أو نواة مستقلة محسومة قبل كل سؤال موضعي محدود.
