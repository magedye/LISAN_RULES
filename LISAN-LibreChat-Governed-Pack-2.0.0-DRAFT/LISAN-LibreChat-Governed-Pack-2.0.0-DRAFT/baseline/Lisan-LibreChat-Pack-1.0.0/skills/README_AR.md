# مهارات LibreChat

المجلدات الفرعية التسعة عشر حزم مستقلة، وداخل كل منها SKILL.md مكتفٍ بإجراءاته. المسار الموصى به DEPLOYMENT_SKILLS_DIR في ملف البيئة. لا توجد scripts أو allowed-tools أو مراجع دراسات قديمة داخل المهارات.

اختر لكل وكيل المهارات المحددة في ملف setup الخاص به. Available to agent لا يعني تطبيقًا في كل دور؛ هذه الحزمة تستخدم المهارات عند الحاجة، وتحفظ القواعد الملزمة في Instructions لكل وكيل. لم نضع always-apply على التسعة عشر حتى لا يدخل كل إجراء في كل سؤال. إذا لم يُظهر المضيف المهارات أو لم يحقنها فالعمل ليس مؤهلاً تلقائيًا؛ اتبع اختبارات القبول.

يمكن رفع كل ملف منفردًا عبر واجهة Skills عند عدم استعمال النشر، بحساب مخول للإنشاء. لا ترفع مجلد sources إلى Skills أو RAG. مهارات ChatGPT الأصلية محفوظة كمراجع وليست حزمة Agent Plugins لLibreChat.
