# lisan-cumulative

هذه مهارة إجرائية ضمن حزمة لسان 1.0.0، وليست مصدرًا دلاليًا أو صلاحية جديدة. تُطبق مع تعليمات الوكيل الثابتة. لا توسع الأدوات ولا تمنح قبولًا؛ لا ملف allowed-tools فيها. استدعها عند تحقق وصفها فقط.

افصل البحث المستقل عن CUMULATIVE_COMPARISON. أعلن الدراسات المقروءة وأعد التحقق من شواهدها. خادم هذه الحزمة سبع أدوات قراءة وفحص ولا save/get repository. سلّم نسخة قابلة للتصدير مع بيانات المصدر والبحث والاعتراضات والتبعيات؛ لا تقل تم الحفظ إلا بدليل خارجي فعلي. لا تستخدم Memory مخزنًا للمعنى المقبول. إذا وُصلت لاحقًا خدمة السجل الحقيقية فابدأ بفحصها والتزم عقودها وexpected_revision وidempotency_key؛ التعارض يتطلب مراجعة ولا يجيز الكتابة فوقه. REOPEN_REQUIRED لا يعامل كنتيجة جارية مقبولة. المراجعة البشرية الموثقة لا تغير ثوابت السجل الأصلي ولا تثبت استقلالًا تلقائيًا.

في المسار الداخلي تقتصر الأدلة الأولية على المتن المسترجع. نتائج البحث السابق والمصادر الخارجية لا تدخل إلا في مقارنة معلنة منفصلة. عند التعذر بيّن النقص ولا تستبدل الأدلة بذاكرة النموذج. أخرج ما نُفذ فعلًا وما بقي، مع مراجعة دلالية غير مدعاة وثقة غير مختلقة.


إجراء الإجابة من نتيجة مراجعة: إذا لم يطلب المستخدم بحثًا مستقلاً، افحص أولًا البطاقة/الدراسة التي قدمها صراحة أو التي استرجعتها خدمة مخولة متاحة فعلاً. تحقق من معرفها وإصدارها ونطاقها ومصدرها وسجل مراجعتها والاعتراضات وشروط إعادة فتحها. إذا تعذر إثبات حداثة المراجعة فقدمها بوصفها دراسة سابقة، لا نتيجة جارية مؤهلة. عند تطابق النطاق أعط إجابة مسندة إلى ذلك الإصدار مع إعادة التحقق من الشواهد المؤثرة دون إعادة الاستقراء كله. عند نقص النطاق ابحث الجزء غير المغطى. لا تجعل الاستنتاج السابق شاهدًا قرآنيًا أوليًا. إذا لم يتوفر سجل فعلي فصرّح بذلك ثم ابدأ البحث المناسب؛ لا تفترض أن Memory مخزن مؤهل. هذا إجراء جواب وتوجيه، لا mode جديدًا في schema الأدوات.

عند ظهور دليل مضاد أو تغير مصدر/منهج سجل النتيجة والتبعيات المتأثرة وسبب إعادة الفحص. لا تستبدل الإصدار السابق تلقائيًا، ولا تستدع Blind Lab إلا لسبب تشخيصي مناسب. عرض نتيجة مراجعة لا يساوي إعادة اختبار كل فرضياتها؛ ادعاء جديد أو توسيع نطاق يحتاج فحوصه.
