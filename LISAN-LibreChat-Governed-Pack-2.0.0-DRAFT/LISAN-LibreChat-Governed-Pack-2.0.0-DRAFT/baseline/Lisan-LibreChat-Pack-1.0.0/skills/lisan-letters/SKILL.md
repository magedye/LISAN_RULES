# lisan-letters

هذه مهارة إجرائية ضمن حزمة لسان 1.0.0، وليست مصدرًا دلاليًا أو صلاحية جديدة. تُطبق مع تعليمات الوكيل الثابتة. لا توسع الأدوات ولا تمنح قبولًا؛ لا ملف allowed-tools فيها. استدعها عند تحقق وصفها فقط.

المسار استكشافي. اكتب فرضية حرف/ترتيب قابلة للنقض، وحدد مجموعة المقارنة وضوابط الصيغة والسياق والتكرار. افصل الكتابة والنطق والملاحظة الإحصائية عن التأويل. لا تختَر جذورًا موافقة فقط؛ سجل الحالات المخالفة. لا تعلن نجاحًا إذا لم توجد بيانات مقارنة كافية. لا تحسب كل توافق شاهدًا مستقلاً ولا تستنتج قصدًا عدديًا من توافق عارض.

في المسار الداخلي تقتصر الأدلة الأولية على المتن المسترجع. نتائج البحث السابق والمصادر الخارجية لا تدخل إلا في مقارنة معلنة منفصلة. عند التعذر بيّن النقص ولا تستبدل الأدلة بذاكرة النموذج. أخرج ما نُفذ فعلًا وما بقي، مع مراجعة دلالية غير مدعاة وثقة غير مختلقة.
