# ملفات الإعداد

- librechat.native.yaml: Windows، إعداد المثيل المخصص ومرحلة إنشاء الوكلاء.
- librechat.trial-locked.yaml: نفس الملف بعد إخفاء اختيار النموذج وإغلاق إنشاء Agents/Prompts للباحث العادي. يلزم فحص Roles والملكية الفعلية؛ Admin ليس مقيدًا بهذا كحد أمان غير قابل للتجاوز.
- native.env.example: سطرا الربط في بيئة المثيل، دون أسرار أو مزود نموذج مفترض.
- librechat.external.yaml وexternal.env.example: خيار مثيل خارجي مستقل لـCOMPARE/SCIENCE/HISTORY؛ البحث وجلب الصفحات بواسطة Tavily يحتاجان مفتاحًا حقيقيًا. قيمة المفتاح فارغة عمدًا، فلا يعد الاتصال جاهزًا أو مختبرًا.
- librechat.container.yaml وcompose.lisan.override.yaml: بديل حاوية، لا يطبق مع native ولا يعد نشرًا مستقلاً. لم تُختبر حاوية في المهمة.

toolApproval يسمح بأسماء الأدوات السبع صراحة بدل كل أدوات خادم مستقبلية. mode=default يطلب مراجعة للأدوات غير المطابقة وفق سياسة المضيف، ولا يخلق حظر شبكة على النظام. capabilities والقائمة المختارة لكل Agent حدود إضافية يجب فحصها داخل LibreChat. لا تضف أداة حفظ/ويب/ذاكرة إلى هذا الملف لتجاوز نقص وظيفي؛ استخدم المسار المنفصل الموثق.

ملفات YAML هنا كاملة للخيارات التي تقررها الحزمة، وتترك إعدادات المصادقة والمزود وقاعدة بيانات المثيل لقيمه الفعلية. لا تُستبدل .env العامل بهذه الملفات. نجاح schema validation لا يثبت صحة صلاحيات النشر أو اتصال النماذج.
