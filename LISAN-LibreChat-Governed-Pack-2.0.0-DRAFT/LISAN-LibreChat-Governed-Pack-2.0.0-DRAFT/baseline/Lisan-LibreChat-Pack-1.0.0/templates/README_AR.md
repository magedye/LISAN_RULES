# استعمال القوالب

القوالب هنا دفاتر يملؤها المشغّل، وليست import schema لـLibreChat ولا مدخلات جاهزة لـlisan_check_study. null يعني لم يسجل/لم يتحقق، وليس صفرًا أو PASS. لا تحول كل خانة فارغة إلى ادعاء من النموذج.

للفحص الأصلي استخدم الغلاف والسجل الناتجين عن أدوات المرشح، مع schemas المنقولة في sources/candidate-references/schemas. احتفظ بالملف الأصلي دون تغيير، واربطه بالدفتر ببصمة ومسار. OUTPUT_TEMPLATES_LEGACY مصدر تاريخي، لا يبدل العقد النافذ.

RUN_WORKBOOK للتوثيق؛ REVIEW_RECORD لقرار مراجع محدد النطاق؛ EXPOSURE_RECORD لما أمكن ملاحظته من السياق؛ EVAL_RECORD لفحص منفذ؛ RESULT_CARD للعرض؛ DEPENDENCY_REGISTER لأثر التغييرات اليدوي؛ DEPLOYMENT_RECORD للقيم التي تنشئها واجهة المثيل بعد الإعداد. لا توجد ملفات نتائج معتمدة أو مراجعات وهمية جاهزة في هذه القوالب.


DIAGNOSTIC_COMPARISON يقارن نسخة BLIND المنتهية بالأصل، مع تساوي النطاق والتغطية والأسباب المحتملة للفروق. لا يثبت سببًا داخل أوزان النموذج ولا يمنح اعتمادًا.
