# ترتيب التبني ومعايير الانتقال

| المرحلة | النتيجة المطلوبة | دليل الخروج |
|---|---|---|
| 1 — تهيئة مثيل مخصص | YAML و19 مهارة وخادم سباعي ظاهر في LibreChat | تشغيل status واسترجاع واقتباس داخل الواجهة، نسخة ومزود مسجلان |
| 2 — البحث الأساسي | COLLECT/MORPH/SEM/CRITIC/AUDIT ثم ORCH | دراسة صغيرة قابلة للتتبع، مع حالات T01–T12 المناسبة |
| 3 — الاستقلال والمقارنة | BLIND جديد وتصدير نسخته ثم COMPARE منفصل | سجل تعرض ونسختان محفوظتان وإظهار الخلاف دون توريث اعتماد |
| 4 — التنظيم والتراكم اليدوي | دفاتر بحث وقرارات مراجعة وتبعيات | إعادة فتح دراسة محفوظة وإعادة فحص شواهدها في النطاق المعلن |
| 5 — المسارات الخارجية | علم وتاريخ بمصادر فعلية | توثيق الوصول والفصل بين النص والخبر/الدعوى الخارجية |
| 6 — الإنفاذ الدائم عند الحاجة | C01–C05 على خدمة المجال/المضيف | اختبارات منع التجاوز، هوية ومعاملات وتبعيات ومراجعة مستقلة |

لا يلزم تشغيل كل وظيفة في السؤال الواحد، ولا يوجد تقدير زمني أو تكلفة نموذج موثوق قبل تجربة المزود الفعلي. ابدأ بعينة صغيرة تقيس فائدة توزيع الأدوار مقابل زمنها وتكلفتها. إذا لم تضف وظيفة قيمة مقاسة فتبقى مهارة/إجراء، مع الحفاظ على تتبعها.

مرجع التشغيل هو النسخة المراجعة من الإعداد والتعليمات، ثم نتائج التقييم المرتبطة بها. تعديل مدلول الدور أو أدواته أو المصدر يوجب مراجعة الأجزاء المتأثرة. اعتماد إصدار أو توسيع جمهور الخدمة قرار منفصل عن اكتمال هذه الحزمة.

الخطوة التالية الموصى بها: تهيئة نسخة تجريبية مخصصة وفق الدليل، ثم تنفيذ قبول المسار الداخلي قبل بناء مخزن المعرفة الدائم. لم تنفذ هذه الخطوة ضمن المهمة الحالية.
