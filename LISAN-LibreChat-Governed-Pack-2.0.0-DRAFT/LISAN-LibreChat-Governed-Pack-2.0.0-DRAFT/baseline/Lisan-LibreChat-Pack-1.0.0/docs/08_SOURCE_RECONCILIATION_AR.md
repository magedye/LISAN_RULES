المراجع الأصلية في sources محفوظة للباحث والمشغّل، وليست حزمة سياق يجب رفعها كلها. بعضها يتضمن وصفًا تاريخيًا لاتصال Site أو لنسخة أقدم؛ لا يصلح ذلك إثباتًا لبيئة اليوم. الملفات المسماة LEGACY ليست عقد الإخراج النافذ، ولا نستورد منها حالات أو أقفالًا.

المهارات السبع في المرشح الأصلي مغطاة هنا: study وcontext وcompare وoccurrences وverify تقابلها المهارات ذات الأسماء نفسها؛ hypothesis أصبحت lisan-falsify؛ setup وزعت على lisan-route وlisan-evidence. المهارات الإضافية تفصل إجراءات المنهج نفسها، ولا تستورد مراجع خارجية. وظائف Site التراكمية لم تُسمَّ أدوات متاحة في هذه النسخة السباعية.

تخصيص «وكيل لكل وظيفة» تحقق وظيفيًا بمالك ومسار لكل بند؛ التجميع التشغيلي لا يلغي فصل طبقات التحليل. إن كشف التقييم لاحقًا أن فصل مهارة إلى Agent يحسن دقة مقاسة فيمكن ذلك، مع تحديث الصلاحيات والعلاقات والتكلفة، لا بدافع زيادة الأسماء.


للمواد الأحدث التي ظهرت أثناء العمل، بما فيها مسار الذاكرة أولًا وAGHR، راجع [مصالحة First-Docs](12_FIRST_DOCS_RECONCILIATION_AR.md). لم تُنقل ادعاءات القفل أو الحالات المقترحة إلى schema المرشح.
