# جرد الوظائف الـ37 وتوزيعها

المحافظة على كل وظيفة لا تعني تخصيص نموذج مستقل لكل إجراء. اختيرت عشرة Agents، مع خدمات قراءة وفحص وقوالب ومراجعة بشرية؛ حدود النقص صريحة لكل وظيفة. لا ندمج الأقوال الخارجية في نقد المسار الداخلي.
