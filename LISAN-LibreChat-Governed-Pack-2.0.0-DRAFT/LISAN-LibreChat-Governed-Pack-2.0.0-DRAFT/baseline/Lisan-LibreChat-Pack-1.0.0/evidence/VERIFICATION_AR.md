مصدر LibreChat الرسمي الذي قرئ هو `61892206974618971b9001d109485d994dac2816`، ويعلن `v0.8.9-rc1`. المصدر المحلي المقروء `74ccf8e3654a0ec5bbae537d9339e622c0625885` ويعلن `v0.8.8` مع أعمال مالك قائمة حُفظت. الفحص يستخدم TypeScript/Zod/js-yaml وMCP SDK المثبتة محليًا؛ إصداراتها في SOURCE_BASELINE، وليس بناءً كاملاً لتوزيعة LibreChat الجديدة.

أُصلح أثناء إعداد فحص SDK خطأ في سكربت الفحص نفسه: حالة رفض الاقتباس المحرّف تعيد isError=true عمدًا، وكان المساعد الاختباري يشترط نتيجة غير خطأ قبل فحصها. صُحح توقع الحالة السلبية وأعيد هذا الفحص بنجاح؛ لم يتغير runtime. هذا TEST_DEFECT في فحص الحزمة، وليس خللًا جرى إصلاحه في المنتج.

نتيجة الخادم READY_FOR_CORPUS_OPERATIONS وبصمة النسخة لا تثبت الأصالة مستقلةً أو قبول الاستنباط. لم نستعمل نصًا مولدًا من النموذج شاهدًا، ولم ننفذ تحليلًا دلاليًا أو أي استدعاء LLM سحابي. الفحص العدائي داخل الواجهة ومراجعة الدلالة وحالات T01–T12 وLC01–LC21 جميعها تنتظر التهيئة الفعلية وفق خطة القبول.
