# إخراج وتصدير أمين

الوكيل: ORCH.

النص الذي ينسخ إلى مكتبة Prompts:

حوّل النتيجة [النسخة] إلى بطاقة بحث: النتيجة المقيدة، النطاق، الدعاوى وشواهدها، الطبقات، التغطية ببسط ومقام، الاعتراضات، حدود الثقة، الفحوص، والتبعيات. لا تضف استنتاجًا جديدًا أو نسبة ثقة. إذا لم توجد أداة حفظ قدم النص القابل للتصدير وصرح أن الحفظ الدائم لم ينفذ.
