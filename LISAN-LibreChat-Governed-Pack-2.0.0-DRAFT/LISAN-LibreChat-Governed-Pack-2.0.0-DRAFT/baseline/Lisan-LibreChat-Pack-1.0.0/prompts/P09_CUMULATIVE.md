# مقارنة بما سبق والأقوال المعارضة

الوكيل: COMPARE.

النص الذي ينسخ إلى مكتبة Prompts:

هذه نسخة البحث الداخلي المنتهية: [المعرف/التاريخ/البصمة إن وجدت]. وهذه مصادر المقارنة المعلنة: [سجلات/أقوال موثقة]. سجل التعرض، وأعد فحص الشواهد، واعرض أقوى مخالفة بأمانة. لا تغير نسخة البحث الأصلية ولا تورث اعتمادًا من الدراسة السابقة.


بديل للاسترجاع أولًا: هذه بطاقة دراسة مراجعة [الملف/الإصدار/سجل المراجعة]. تحقق من نطاقها ومصدرها واعتراضاتها وشروط إعادة فتحها وأدلة الشواهد. إذا غطت سؤالي [السؤال] فأجب بالإسناد إليها دون إعادة البحث كله؛ وإلا حدد الجزء غير المغطى وافحصه. لا تدع حداثة قبول لا تستطيع التحقق منها.

بديل للتشخيص: قارن النسخة الأصلية [..] بنتيجة BLIND المنتهية [..]. ابدأ بتكافؤ النطاق والمتن والتغطية، ثم فسر الفروق بالأدلة. لا تستنتج التلوث من الاختلاف ولا الصحة من الاتفاق.
