# حزمة تبنّي لسان القرآن في LibreChat — 1.0.0

الحزمة جاهزة للتهيئة اليدوية والفحص على نسخة مخصصة من LibreChat. تتضمن إعدادات فعلية، وتعليمات عشرة وكلاء، وتسع عشرة مهارة، ومكتبة أوامر، وقوالب سجلات، وخادم MCP محليًا منقولًا دون تعديل من الحزمة السابقة. لا تتطلب تغييرًا في شفرة LibreChat أو خادم لسان لبدء المسار البحثي المحدد هنا.

**القرار:** اعتماد LibreChat واجهة تشغيل للوكلاء والمهارات والتفويض، وإعادة استخدام أدوات لسان للاسترجاع والفحص. الاحتفاظ بالوظائف الـ37 والطبقات الثلاثين، مع تجميع التنفيذ في عشرة وكلاء. الحفظ والقبول الدلالي واستقلال المراجعة ليست وظائف تنتج تلقائيًا من Memory أو تعدد الوكلاء.

**حد التسليم:** إنشاء هذه الحزمة وفحصها محليًا؛ لم تُثبت في التطبيق، ولم تتغير إعدادات نسخة LibreChat العاملة، ولم تستدعَ نماذج سحابية. الفحص المحلي لا يثبت جودة التفسير أو التأهيل داخل واجهة LibreChat. التفاصيل في [تقرير التحقق](evidence/VERIFICATION_AR.md).

## ابدأ من هنا

1. اقرأ [القرار وحدود التبني](docs/01_DECISION_AR.md) و[مصفوفة مكونات LibreChat](docs/02_COMPONENT_MATRIX_AR.md).
2. اتبع [دليل الإعداد والتشغيل](docs/03_SETUP_AND_OPERATION_AR.md). ملف Windows: [librechat.native.yaml](config/librechat.native.yaml)، ومتغيرا الربط في [native.env.example](config/native.env.example).
3. أنشئ الأطفال الخمسة ثم ORCH ثم BLIND، وأضف COMPARE وSCIENCE وHISTORY عند الحاجة. [فهرس الوكلاء](agents/README_AR.md) يربط كل ملف تعليمات بورقة إعداده.
4. تحقق من المهارات عبر [فهرسها](skills/README_AR.md)، وأضف أوامر [مكتبة Prompts](prompts/README_AR.md).
5. شغّل حالات [القبول السلوكي](docs/09_ACCEPTANCE_AR.md) على المضيف والنموذج المختارين، وسجل المخرجات قبل وصف التشغيل بالمؤهل.

عقود الخادم السباعي وطريقة استخدامه وحدود إيصالاته موضحة في [دليل MCP](docs/11_MCP_CONTRACT_AR.md). إعداد البحث الخارجي الاختياري موضح في دليل التشغيل ويستخدم مثيلًا منفصلًا ومفتاح Tavily يضعه المشغّل؛ لم ينفذ اتصال خارجي أثناء تجهيز الحزمة.

## خريطة الحزمة

| المسار | المحتوى |
|---|---|
| docs/ | قرارات، مكونات، تشغيل، علاقات، مصدر وذاكرة، تتبع 37 وظيفة و30 طبقة، مصالحة المصادر، قبول، وخطة تبنّي |
| agents/ | 10 ملفات Instructions كاملة، و10 أوراق إعداد، وفهرس CSV |
| skills/ | 19 حزمة SKILL.md مستقلة؛ بلا أدوات توسّع الصلاحيات أو ملفات دراسات قديمة |
| prompts/ وprojects/ | نصوص جاهزة للنسخ إلى المكتبة وتعليمات المشاريع المسموحة |
| config/ | إعداد Windows، وإعداد حاوية ومسار ربط للمهارات، وملف إغلاق إنشاء المستخدمين أثناء التجربة |
| runtime/ | 15 ملفًا أصليًا من خادم stdio ذي 7 أدوات قراءة وفحص؛ Node 22 أو أحدث |
| templates/ | تكليف فرعي، سجل تعرض، دفتر بحث، بطاقة نتيجة، مراجعة، اعتماديات، تجربة نموذج |
| appendix/ | فجوات الإنفاذ والحفظ وتفاصيل التطوير المقترح دون تنفيذه |
| sources/ | نسخ المصادر الداخلة، وعقود المرشح الأصلية، والمراجع الرسمية المؤرخة |
| evidence/ وchecks/ | بصمات وفحوص قابلة للإعادة، مع فصل ما اختُبر عما لم يختبر |

مرجع التوافق: شفرة LibreChat عند `61892206974618971b9001d109485d994dac2816`، التي تعلن `v0.8.9-rc1`، فُحصت في 22 أكتوبر 2026. هذه نسخة مرشحة وليست توصية إنتاجية تلقائية. النسخة المحلية المشاهدة `v0.8.8` عند `74ccf8e3654a0ec5bbae537d9339e622c0625885`؛ نتائج توافقها محددة في تقرير الفحص.

اعتُبرت حزمة `Quran_Lisan_Complete_Package_2026-10-14.zip` المقصودة بعبارة «الحزمة الحديثة» بعد العثور عليها، ولم يرد تأكيد مستقل للمسار. هذا افتراض موثق، ويمكن مقارنة حزمة أخرى لاحقًا دون خلط هويات المصادر. حُفظت الوثائق الأصلية كما هي للرجوع، ولا تُحقن كلها في الوكلاء.
