# المعمارية والسلطة الفعلية

## أساس التنفيذ
تكليف المالك الأخير يجيز تطوير منظومة تراكمية مع حفظ الموجود. المرجع الدلالي باقٍ `QURAN_INTERNAL_STRICT` والسياسة الموجودة؛ لم نغيّر Corpus أو pin أو kinds مخطط 2.0. حزمة supplement مرجع تصميم ومصالحة، لا مصدر أدلة معنى. استفدنا من مرجع LISAN3 V3 المثبت في Git عند `48704e52092c65c0abfb0a4ffc43745f1285499b`؛ لم ننقل قاعدة بياناته أو إجراءات قبوله أو بوابات تجميد عامة.

مسار التنفيذ: ChatGPT + المهارات → MCP ذو مصادقة المضيف القائمة → `composeResearch` → النواة القديمة أو Repository → مخزن D1/SQLite. واجهة Site تستخدم API محميًا من الخادم نفسه. المكتبة لا تقرأ هوية من query/body أو رؤوس مصطنعة؛ تُحقن هوية مخولة من المضيف.

## البيانات
`lisan-repository-document/1` غلاف إضافي حول `quran-lisan-study/1` أو record2.0. يحتفظ النص الأصلي للوثيقة ومعرف الدراسة الداخلي كما هو؛ معرف التخزين الخارجي مستقل عنه. يسمح الغلاف بحفظ مسودة صفر دعاوى، لكن المدقق القديم 2.0 لا يُغير ليصفها دراسة مكتملة.

الجداول الدائمة: الدراسات، الإصدارات، فهرس الدعاوى، فهرس الشواهد، الاعتماديات المثبتة بالإصدار، المراجعات، أحداث التدقيق، ومفاتيح idempotency. تحفظ الملاحظات والفرضيات والطبقات والتفريد والاختبارات داخل وثيقة الإصدار الأصلية غير القابلة للاستبدال، ولا تُنشأ جداول متوازية بلا حاجة.

كل كتابة عملية واحدة ذرية. يدافع SQL عن تسلسل الإصدارات، ومطابقة الأصل، وعدم الدوران، وبقاء هدف المراجعة، وعدم استعمال مراجعة سُحبت أثناء بناء السياق. انقسام الاتصال بعد COMMIT لا ينتج نسخة مكررة عند إعادة المفتاح نفسه. SQL وحمولات أصلية مقيدة داخل الخدمة؛ لا أداة SQL/URL/path عامة.

## المعرفة والمراجعة
يحفظ الحكم البحثي القديم `PREFERRED/UNRESOLVED/REJECTED` في موضعه. المراجعة الجديدة سجل منفصل: `REVIEWED_WITHIN_SCOPE/NEEDS_WORK/REJECTED`، مربوط بالإصدار والبصمة والنطاق، وموسوم `NOT_ESTABLISHED` للاستقلال. ليست محور قبول LISAN3 الرسمي، ولا تحول `canonical_state` عن `NOT_CANONICAL`.

ذاكرة المقارنة لا تسترجع إلا إصدارًا حاليًا غير معزول وغير محتاج لإعادة فحص، اجتاز الفحص وأضيفت له مراجعة مالك صريحة ضمن نطاقها. يُعاد فحص مصدره قبل إرجاع ملخصه، وتسجل واقعة التعرض. لا يدخل محتوى الدراسات السابقة مسار INDEPENDENT. هذا ضمان لحمولة الأداة فقط، لا محو ذاكرة النموذج أو ما رآه سابقًا في المحادثة.

إعادة الفتح تعمل حاليًا على مستوى الدراسة واعتمادياتها، لا تحليلًا دقيقًا لكل جزء من دعوى. تغيير الأصل يوسم التوابع ولا يحذف تاريخها. شبكة العلاقات إسقاط مشتق للعرض؛ لا تستنتج معنى ولا تجعل الحافة حجة قرآنية.

الحقول والفحوص تثبت المراجع والاقتباسات والعد والتغطية المصرح بها. محتوى الملاحظة ووجه الاستدلال ونتيجة النقض يحتاج قراءة بشرية/نموذجية ومراجعة بحثية. لا يكفي وجود نص غير فارغ لإثبات تحليل عميق. لا توجد عتبة ثقة دلالية رقمية أو نتيجة ذهبية موروثة.
