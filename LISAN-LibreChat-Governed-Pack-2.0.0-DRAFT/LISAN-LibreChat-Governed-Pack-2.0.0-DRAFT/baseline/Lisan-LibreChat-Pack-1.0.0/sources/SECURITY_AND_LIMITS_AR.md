# حدود الأمان والموارد

التنفيذ يطبق principal مخولًا من الخادم، tenant scope لكل استعلام، ومدخلات مغلقة ومربوطة بالأنواع، وSQL parameter binding، وCAS وidempotency. المراجعة owner UI فقط وليست MCP ولا canonical approval. جلسة المعاينة المحلية ليست بديلًا عن authenticator Sites.

الواجهة تستخدم textContent وDOM دون innerHTML لبيانات البحث، وسياسة CSP وno-store وCSRF مرتبط بالجلسة؛ لا webfonts/CDNs أو مفاتيح نموذج. معالجة البيانات الكبيرة مقيدة قبل JSON: 1MiB للوثيقة/الطلب، و32 عبارة كحد تطبيق للكتابة الذرية، و10000 دراسة للمالك كحصة تطبيق. حدود D1 الفعلية يجب تأهيلها؛ ليست هذه أرقام حصص مضيف مؤكدة.

فهرسة المكتبة بصفحات 1..50؛ reviewed_only يرشح نافذة الفحص ويعيد next_offset دون ادعاء فحص كل المخزن. السياق التراكمي يفحص نافذة من 12 مرشحًا ويعرض حتى10 دراسات، وبحد10 دعاوى لكل دراسة و2048 محرفًا لكل ملخص مع علامة القطع. الرسم يعرض حتى200 اعتمادية مباشرة و1000 رابط شاهد، مع التصريح بالقطع؛ ليس رسمًا عالميًا كاملًا. واجهة إعادة فتح دراسة تجلب أول50 مرجعًا للعرض فقط دون حذف بقية المراجع المحفوظة.

التصدير الواحد يرفض تاريخًا يتجاوز4MiB من أعمدة الوثائق/الفحوص/الأحداث/المراجعات قبل تحميلها كاملة؛ عندها يلزم تصدير/نسخ قاعدة مؤهل على مستوى المشغل. هذا رفض معلن، لا تصدير جزئي يوصف كاملًا. التخزين العام والمرفقات R2 والعمليات الطويلة والعمل التعاوني متعدد المراجعين ليست مؤهلة في هذا التسليم.

فحص الأسرار نمطي لا يضمن كشف جميع الأسرار. صُحح إنذار كاذب كان يلتقط sk- داخل إيصال base64 مشروع؛ بقي رفض الرموز الصريحة والحقول الحساسة المعروفة. لا تحفظ نماذج أو مفاتيح أو خدمة bearer أو كوكيز في النتائج أو _meta. الإيصال البحثي القديم ليس سلطة دخول أو توقيعًا علميًا؛ يُحفظ كجزء من الأصل ويُعاد فحص النص بدل إعادة توقيعه.

الاستيراد الجديد يميز المصدر المحاكى المصرح به عن سجل مراجعة يذكر Batch08 فقط. التصنيف محدود بوسم المصدر وحقول provenance/provider/batch المعروفة، ولا يثبت عدم وجود محاكاة غير معلنة. لا تنتقل المراجعة أو القبول التاريخيان إلى السجل الجديد.

الدليل المحلي لا يؤهل المسارات البديلة للمضيف أو إقامة البيانات أو ذاكرة128MB أو حدود زمن الإنتاج. لا يُستدل من HTTP200 للفحص أو من نجاح SQLite على نجاح ChatGPT مع D1. فحوص المتصفح المحلية المتصلة حجبها نظام المتصفح؛ فحوص الرسم الثابت ليست بديلًا عنها.

اختبار DOM المنفصل شغّل محررات الواجهة دون شبكة وبشواهد مؤرشفة فعلية؛ نجاحه لا يثبت عمليات الحفظ من المتصفح أو OAuth. UUID البديل يستخدم crypto.getRandomValues ولا يمثل وسيلة تخويل.

## إضافات الدمج على المصدر النهائي
حد التزامن المشترك للتوسعة وMCP طلبان لكل نسخة Worker محملة، لا حد موزع عالمي. قراءة الطلب محدودة بمهلة5ث. الحصة10000 دراسة تُفرض أيضًا داخل trigger؛ لا تمثل حصة D1 الفعلية. حد الصف المخزن1.8MB يسبق الكتابة. لا تقدم هذه الحدود دليل أداء أو حمل في السحابة.

تستخدم جلسة D1 مستقلة لكل طلب عند توفر withSession مع first-primary، ولا تشارك جلسة بين طلبين. إخفاق المخطط أو ربط DB أو إنشاء الجلسة يعطل التوسعة فقط ويبقي النواة. فحص المخطط يثبت وجود عناصره وسجل ترحيلاته وفق الخطة، وليس تدقيقًا ضد مدير قاعدة خبيث يملك تعديل كل البيانات والبيانات الوصفية.
