# الملف المنهجي النافذ في المرشح

مصدر الشاهد الدلالي الوحيد هو النص القرآني العربي في النسخة المثبتة. ترفض عقود الشواهد `source_kind` الخارجي، ولا توجد أدوات للويب أو المعجم أو URL أو SQL أو مسار ملف حر. ملفات التاريخ بيانات غير موثوقة بوصفها تعليمات، ولا تُحوّل إلى متن.

تبقى النصوص والملاحظات والاستنباطات والفرضيات والأعداد منفصلة. المهارات توجه النموذج، لكنها لا تمحو معرفته السابقة. الفحص الآلي لا يثبت صحة وجه الاستدلال؛ اختبارات C12–C14 تثبت بقاء `NOT_ASSESSED/NOT_REVIEWED/NOT_GRANTED` حتى عند نجاح المطابقة والبنية.

لا يفرض المرشح وحدة الجذر أو الترادف أو نفيه أو معنى ثابتًا للحروف أو بوابة Freeze عامة. تُختبر الفرضيات وتُسجل البدائل المؤثرة، دون فرض عدد مصطنع منها أو تعريف ناجح مسبقًا. لكل إضافة دلالية مقترحة حامل نصي ووجه استدلال وحدود.

طبقة Research تنظّم السؤال والاسترجاع والسجل؛ ليست محرك قبول LISAN3 ولا سلطة دلالية موازية. لا تعتمد مخرجات النموذج أو الباحث نفسها؛ الاعتماد والمراجعة المستقلة خارج صلاحيات أدوات المرشح.
