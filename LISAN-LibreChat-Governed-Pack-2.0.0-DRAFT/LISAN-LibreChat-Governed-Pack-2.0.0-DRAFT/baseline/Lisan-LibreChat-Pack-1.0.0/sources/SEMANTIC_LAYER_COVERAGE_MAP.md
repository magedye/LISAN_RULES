# خريطة الطبقات الثلاثين

بُني اختيار selected_layers وسجل status/observation/evidence، ومساهمات claim_dimensions لكل جزء مقترح مع الحامل النصي ووجه الاستدلال. تفحص الآلة وجود الحامل واتساق المراجع ومطابقة النص، ولا تحكم بصحة نسبة المعنى إلى طبقة معينة.

النص وسياقه قابلان للاسترجاع، وQAC يوفر بيانات بنيوية مصفاة مع حدود مواءمة معلنة. الأدوار الدلالية والإحالة وبنية الخطاب والمقابلات والعلاقات المفهومية أعمال بحثية موجهة، وليست محللات آلية مؤهلة. لا شجرة head/dependent ولا Graph لمعانٍ مقبولة.

يحفظ `registers/METHOD_LAYER_MAP.csv` أسماء طبقات المصدر ويميز ما بقي إرشاديًا عما دعمه الكود. اختيار الطبقة لا يعني تنفيذ تحليلها، ولا يلزم المرور بالثلاثين لكل سؤال. هذه الخريطة لا تستورد إذن الشواهد الخارجية من الوثيقة النظرية الأوسع.
