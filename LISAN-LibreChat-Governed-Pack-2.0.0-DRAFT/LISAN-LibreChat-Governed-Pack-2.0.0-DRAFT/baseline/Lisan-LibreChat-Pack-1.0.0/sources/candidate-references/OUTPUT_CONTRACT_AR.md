# عقد مخرج الباحث — المرشح
ابدأ بالنتيجة المقيدة ثم نطاق البحث والشواهد والملاحظات وفرضيات المعنى والبدائل والاعتراضات والقيود وحالة التحقق. وضح ما حلل فعلًا وما لم يحلل؛ الاختصار لا يخفي نقصًا مؤثرًا.

استعمل record2.0 الأصلي، وغلاف الدراسة الموضح في [CANDIDATE_RECORD_AR.md](CANDIDATE_RECORD_AR.md). لا تستخدم عقدًا قديمًا أو قالبًا مثاليا لتغيير schema. DIRECT_TEXT نقل لا تأويل؛ OBSERVATION ملاحظة؛ SUPPORTED_INFERENCE استنباط؛ TENTATIVE_HYPOTHESIS فرضية؛ COUNT عد حرفي يعاد حسابه. UNRESOLVED حكم بحثي لا kind جديد.

الفحص الآلي منفصل عن مراجعة الدلالة وعن المراجعة المستقلة والاعتماد. لا نسب ثقة مخترعة، ولا RELEASE_ACCEPTED أو استقلال مطلق عن التدريب. قدم ملخص استدلال علنيًا قابلًا للمراجعة، لا سلسلة التفكير الخفية. كل مثال سابق أو ناتج MOCK تاريخ أو اختبار؛ ليس دليلًا دلاليًا جديدًا.
