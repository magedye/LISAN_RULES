# تشغيل المستودع التراكمي — مرشح مهارات غير منشور

## قبل الاستخدام
اكتشف أدوات الإضافة الفعلية. إذا لم توجد `lisan_repository_status` وبقية أدوات المستودع، فقل إن الحفظ الدائم غير متاح في المضيف الحالي واستمر في الدراسة/التصدير المصرح بهما دون ادعاء حفظ. لا تُشغل خادمًا محليًا بديلًا لإثبات أدوات Site. بعد النشر والتأهيل فقط يمكن وصف المخزن بالدائم.

## بناء الدراسة والحفظ
ابدأ بالنية والنطاق وIPP القائم. استخدم الشواهد من النواة المثبتة. غلاف `lisan-repository-document/1` يحوي الدراسة كما هي، والعنوان والملاحظات وبطاقات التفريد والاعتماديات ومرجع المنهج. لا تغيّر schema2.0 أو تطبع الشواهد. قراءة المستودع تعيد إصدارًا وبصمة؛ تمررهما للكتابة المتوقعة. كل عملية حفظ لها idempotency_key ثابت عند إعادة محاولة العملية نفسها. REVISION_CONFLICT يستلزم قراءة آخر إصدار ومقارنة التغييرات، لا سحق عمل المالك أو توليد توقع نسخة جديد تلقائيًا.

الحفظ عملية كتابة وليست اعتمادًا. أنجزه في سياق طلب حفظ أو تفويض تخزين قائم؛ لا تخزن كل محادثة بلا نطاق معلوم. حالات الفشل والدراسات غير المحسومة تبقى مهمة، ولا تصنفها نتائج سيئة يجب إخفاؤها.

## الذاكرة
`INDEPENDENT` لا يعيد دراسات سابقة، لكنه لا يمحو تعرض النموذج السابق. `CUMULATIVE_COMPARISON` مسار صريح يسجل التعرض ويعيد نسخًا مراجعة ضمن نطاقها بعد إعادة فحص المصدر. استنتاجاتها ليست قرآنًا ولا دليلًا أوليًا. لا تستخدمها مقدمة خفية، ولا تصف دراسة بأنها عمياء بعد الاطلاع عليها. إذا ظهرت REOPEN_REQUIRED فلا تقدمها نتيجة مراجعة حالية.

## الطبقات والنقض والتفريد
اختر ما يؤثر في السؤال، واربط كل عنصر دلالي بالشاهد ووجه الاستدلال. وحدة word_ref ثلاثة أجزاء؛ segment_ref أربعة. اكتمال التسجيل ليس إثبات فهم. سجّل الفرضيات وشرط نقضها والاختبارات والمعارض، ولا تُلزم كل سؤال بتعدد فرضيات مصطنع. الاستبدال الافتراضي في بطاقة التفريد ليس نصًا قرآنيًا. المقارنة الآلية تبين تغيير الحقول ولا تحسم التناقض الدلالي.

## إعادة الفتح والمراجعة
ربط دراسة بأصل سابق يثبت إصدار الأصل وسبب الاعتماد. التغير المادي يستدعي lisan_reopen_study أو إصدارًا جديدًا، ويحفظ التوابع والتاريخ. سجل المراجعة من واجهة المالك ليس مراجعة مستقلة أو canonical acceptance؛ لا أداة MCP للقبول الرسمي، ولا تستبدل هذا بفاعل actor يكتبه النموذج. لا تستخدم UI المراجعة نيابة عن الإنسان مدعيًا أنها مراجعة بشرية.

## التاريخ والمخرجات
استورد raw_record/native_states كما هي مع سلالة المصدر وإعادة جلب الشواهد. BSHR/ESw لا يرثان ACCEPTED، ومصادر المحاكاة المعلنة لا تدخل الذاكرة المؤهلة. راع حدود الصفحة والحجم، وصرح بالنقص. الخاتمة تفصل التنفيذ والفحص والحكم البحثي والمراجعة والقبول، ولا نسب ثقة مخترعة.
