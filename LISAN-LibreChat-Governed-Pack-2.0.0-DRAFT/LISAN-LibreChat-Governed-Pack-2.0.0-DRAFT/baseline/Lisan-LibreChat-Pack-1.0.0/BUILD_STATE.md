# حالة الحزمة وحدّ العمل

النطاق المنجز: حزمة تهيئة ووثائق ونصوص وإعدادات في المجلد الذي طلبه المالك، مع إعادة استخدام runtime أصلي وفحوص محلية. لا تغيير في التطبيق العامل أو مشروع LISAN3، ولا تشغيل نماذج أو نشر أو منح اعتماد.

المراجع الواجب فتحها عند الاستئناف: README_AR، docs/03_SETUP_AND_OPERATION_AR، docs/09_ACCEPTANCE_AR، evidence/VERIFICATION_AR، ومصدر LibreChat المثبت وINPUT_CUSTODY. لا تعتمد هذه الورقة بدل العقود أو بدل فحص البيئة التي سيُطبق فيها الإعداد.

القرارات: عشرة وكلاء و19 مهارة؛ ORCH له خمسة أطفال؛ BLIND محادثة جديدة خارج Projects؛ المقارنة الخارجية منفصلة؛ Memory معطلة؛ خادم محلي سباعي بلا حفظ؛ تصدير ومراجعة يدويان؛ C01–C08 تصف تطويرًا مقترحًا غير منفذ.

الحدود الباقية: تكامل UI/النموذج والتصفح والحاوية غير مختبر؛ الحفظ الدائم والإنفاذ الكامل للعزل يحتاجان تهيئة خدمة قائمة أو تطويرًا وفق الملحق. اختيار حزمة 14 أكتوبر بوصفها «الحزمة الحديثة» افتراض موثق.

الخطوة التالية الاختيارية: إعداد مثيل تجريبي مخصص وتعبئة DEPLOYMENT_RECORD ثم تنفيذ حالات القبول. ليس وجود هذه الخطوة تفويضًا ضمنيًا لبدء النشر.


أُدمجت First-Docs قبل التسليم: ذاكرة مراجعة أولًا حيث توجد بطاقة فعلية، Blind Lab اختياري، مقارنة تشخيصية لا تثبت الأصالة بالاتفاق أو التلوث بالاختلاف، و35 بندًا موصولًا بخريطة التنفيذ. ملفات المصادر الخمسة محفوظة ببصماتها.


أُلحقت أيضًا Blueprint ومراجعته النقدية ضمن لقطة المصادر النهائية: 7 ملفات First-Docs، مع ربط 24 فجوة و20 سيناريو، و33 حالة قبول سلوكي غير منفذة. الحزمة لا تستورد حالات مقترحة أو بوابات Lock من تلك الوثائق.
