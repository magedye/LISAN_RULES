## قرارات حاكمة لا يجوز تمييعها

1. الذكاء الاصطناعي **يبحث ويقترح ويستدل وينقد ويختبر**، لكنه لا يثبت أصالة المصدر ولا يمنح الاعتماد أو النشر لنفسه.
2. **المتن القرآني المصدر الأولي**؛ وسم QAC أو MASAQ أو QuranMorph أداة مساعدة تحتاج نسبًا/محاذاة؛ لا يتحول إلى شاهد دلالي تلقائي.
3. `Structured Output` و`hash` وموافقة عدة نماذج ونجاح فحوص ميكانيكية **لا تثبت صحة معنى**.
4. `REUSE_QUALIFIED` مشروط بإصدار ونطاق واعتماد ومراجعة حقيقية، لا بمجرد وجود دراسة محفوظة؛ ويُمنع توريث قبول تاريخي غير متحقق.
5. `INDEPENDENT_DIAGNOSTIC` يعزل السياق والأدوات قدر الإمكان، **ولا يمحو المعرفة التدريبية للنموذج**.
6. كل مخرجات المقارنة الخارجية **بعد القفل وبقسم مستقل**؛ ولا يحق لها تعديل الأصل المقفل دون إصدار جديد ومراجعة.
7. الإعلان عن `FULL` لا يعني «كل معاني الجذر»: يجب تحديد selector ووحدة العد وقائمة مراجع وحجم التحليل. ويظل الفرق واضحًا بين `FULL_DECLARED` و«استقراء دلالي شامل».
8. `SUPPORTED` حكم مراجعة ضمن نطاق؛ `ACCEPTED` اعتماد إداري؛ `RELEASED` قرار نشر مستقل؛ لا يُشتق أحدها آليًا من الآخر.
9. **لا تُعرض نتيجة رسمية إلا عبر حدود نشر موثوقة**. لا يمكن لحزمة تعليمات منع نموذج LibreChat من كتابة جواب حر غير متحقق؛ يعرض بوصفه مسودة.
10. لا تعديلات أو رفع أو نشر على مشاريع المالك من إنشاء هذه الحزمة؛ يلزم تفويض منفصل بعد اجتياز اختبارات البيئة.
